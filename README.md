# England Water Stress Early-Warning Platform

A proof-of-concept early-warning system that translates the Environment 
Agency's public drought-stage data into an automated, personalised, 
forward-looking signal for UK businesses exposed to water abstraction risk.

Built end-to-end using AWS, SQL, n8n, Python, Tableau, and an AI agent 
pipeline, as a technology consulting portfolio project.

See ARCHITECTURE.md (project knowledge base) for full context.
